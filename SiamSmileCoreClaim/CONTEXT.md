# SiamSmileCoreClaimDB - Project Context

## Convention

- หลัง query เสร็จ ให้เอาไฟล์ไปเก็บใน `SiamSmileCoreClaimDB/Opencode-query/` เสมอ
- และ Add เข้ามาใน solution เสมอ
- ไม่ต้อง export session
- หลังทำ query เสร็จถ้าเป็นรูปแบบ SELECT ให้ทดสอบก่อนทุกครั้ง โดยเช็คความถูกต้องของข้อมูลด้วย TOP(100)
